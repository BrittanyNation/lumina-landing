# Lumina — SaaS Landing Page

A fully responsive marketing landing page for a fictional habit-tracking app. Built with pure HTML5, CSS3, and vanilla JavaScript — no frameworks.

## Features

- **Responsive design** — mobile-first, works on all screen sizes
- **Interactive pricing toggle** — monthly/yearly switch with live price updates
- **Scroll-triggered animations** — IntersectionObserver reveal effects
- **Mobile hamburger menu** — accessible toggle navigation
- **Interactive demo** — working "check in" button in the hero phone mockup
- **Dark theme** — modern SaaS aesthetic with CSS custom properties

## Tech

- HTML5 semantic markup
- CSS3 (Flexbox, Grid, custom properties, animations)
- Vanilla JavaScript (ES6+)
